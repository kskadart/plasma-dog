# Установка plasma-dog на Windows — простая инструкция «по шагам»

Эта инструкция написана для людей, которые **не программисты** и просто хотят, чтобы программа заработала. Ничего понимать не нужно — просто повторяй шаги сверху вниз, один за другим. Нельзя «сломать компьютер», следуя этим шагам.

> 🕐 **Сколько это займёт:** примерно 15–20 минут. Из них почти всё время ты просто ждёшь, пока компьютер сам что-то скачивает. Реальной работы руками — минут пять.

> 💬 **Главное правило:** если на экране появилось что-то непонятное или «страшное» — не паникуй и ничего не закрывай. Дочитай шаг до конца, чаще всего так и должно быть. В самом низу есть раздел **«Если что-то пошло не так»** — там разобраны типичные проблемы.

---

## Что тебе понадобится

- Компьютер с **Windows 10 или Windows 11** (обычный рабочий или домашний).
- **USB-камера** (та самая, с которой будешь записывать плазму). Можно воткнуть её прямо сейчас, можно позже.
- **Интернет** (будем скачивать программу и её части).
- Хотя бы **2 ГБ свободного места** на диске (программа и её части весят прилично).
- Около **15–20 минут** свободного времени.

Всё. Никаких дисков, флешек и «прав администратора» заранее искать не нужно.

---

## Шаг 1. Включи компьютер и дойди до рабочего стола

1. Нажми кнопку включения на компьютере или ноутбуке.
2. Дождись, пока загрузится Windows и появится **рабочий стол** (картинка на весь экран со значками).
3. Если просит — введи свой пароль / PIN, как обычно.

Готово, можно продолжать.

---

## Шаг 2. Открой «PowerShell» — это окно для команд

Нам понадобится специальное окно, куда мы будем **вставлять готовые команды**. Оно называется **PowerShell**. Не пугайся — это просто чёрно-синее окно с текстом.

**Как его открыть (самый простой способ):**

1. Нажми клавишу **Windows** на клавиатуре (на ней нарисован флажок-окошко, обычно слева внизу, рядом с пробелом). Откроется меню «Пуск».
2. Прямо с клавиатуры набери слово: **powershell**
3. Сверху в списке появится **«Windows PowerShell»** (синий значок) — нажми на него **левой кнопкой мыши**.

> 🪟 На **Windows 11** вместо «Windows PowerShell» может быть написано **«Terminal»** (Терминал) — это то же самое, нажимай на него.

**Что ты должен увидеть:** откроется тёмное (чёрное или тёмно-синее) окно с текстом. В нём будет строчка примерно такого вида, а в конце будет мигать курсор:

```
PS C:\Users\ТвоёИмя>
```

Это значит, что окно готово принимать команды. **Не закрывай его пока** — оно понадобится дальше. (Один раз, на Шаге 5, мы его специально закроем и откроем заново — я заранее предупрежу.)

---

## Шаг 3. Научись вставлять команды (это умение пригодится много раз)

Дальше я буду давать тебе **готовые команды** в серых рамках. Их не нужно набирать вручную — их нужно **скопировать и вставить**. Делается это так:

1. Наведи мышку на команду в этой инструкции, **выдели её** (зажми левую кнопку мыши и проведи по тексту) и нажми **Ctrl + C** — это «копировать».
2. Перейди в окно **PowerShell**, нажми **левой кнопкой мыши** внутри него (один раз).
3. Нажми **Ctrl + V** — команда вставится.
   - 💡 Если по **Ctrl + V** ничего не вставилось — просто нажми **правую кнопку мыши** внутри окна. В старом PowerShell вставка делается правым кликом.
4. Нажми клавишу **Enter** (большая клавиша «ввод») — команда запустится.

> ✅ **Запомни ритм:** скопировал → вставил → Enter. И так для каждой команды ниже.

---

## Шаг 4. Установи три «детали» (Python, uv, git)

Программе нужны три вспомогательные штуки. Сейчас мы их установим. Это просто три команды — **вставляй их по одной**, после каждой жми **Enter** и **жди**, пока всё скачается.

> ⏳ После каждой команды подожди, пока внизу снова не появится строчка `PS C:\Users\ТвоёИмя>` с мигающим курсором. Это значит «готово, можно следующую». Пока бежит текст или крутится полоска — **просто жди**, ничего не нажимай.

**Команда 1 — Python:**

```powershell
winget install Python.Python.3.13
```

> 📋 При самой первой установке может появиться вопрос вроде *«Do you agree to the source agreements? [Y] Yes / [N] No»* (Согласен ли ты с условиями?). Набери английскую букву **Y** и нажми **Enter**.
>
> 🛡️ Если выскочит окошко с вопросом «Разрешить приложению вносить изменения?» — нажми **«Да»**.

**Команда 2 — uv:**

```powershell
winget install astral-sh.uv
```

**Команда 3 — git:**

```powershell
winget install Git.Git
```

После того как все три команды отработали (после каждой снова появилась строчка `PS C:\...>`) — переходи к следующему шагу. **Следующий шаг (5) — важный, не пропускай его.**

---

## Шаг 5. ⚠️ ОБЯЗАТЕЛЬНО: закрой это окно и открой новое

Это самый частый источник проблем, поэтому отнесись серьёзно:

1. **Закрой** окно PowerShell — нажми на **крестик ✕** в правом верхнем углу окна.
2. **Открой его заново** — снова сделай **Шаг 2** (Пуск → набери `powershell` → нажми на него).

> 🧠 **Зачем:** Windows «замечает» только что установленные программы лишь в новом окне. Если не переоткрыть — следующие шаги будут ругаться, что «команда не найдена», хотя всё установлено правильно.

---

## Шаг 6. Проверь, что всё установилось (необязательно, но успокаивает)

Вставь по очереди эти три команды (каждую — Enter):

```powershell
python --version
```

```powershell
uv --version
```

```powershell
git --version
```

**Что ты должен увидеть** — три строчки с номерами версий, примерно так (цифры могут чуть отличаться, это нормально):

```
Python 3.13.5
uv 0.8.4 (или другая версия)
git version 2.46.0.windows.1
```

Если у всех трёх показались версии — отлично, всё установлено. Если какая-то команда написала «не является именем командлета» или «не распознано» — загляни в раздел **«Если что-то пошло не так»** внизу (пункты 1–3).

---

## Шаг 7. Скачай саму программу

Теперь скачаем программу plasma-dog. Вставь эту команду и нажми Enter:

```powershell
git clone https://github.com/kskadart/plasma-dog.git
```

> ⏳ Побежит текст про «Receiving objects… 100%». Подожди, пока снова появится `PS C:\...>`.

Программа скачалась в твою личную папку. Теперь **зайди внутрь неё** этой командой:

```powershell
cd plasma-dog
```

**Что ты должен увидеть:** строчка слева изменилась и теперь заканчивается на `plasma-dog>`, например:

```
PS C:\Users\ТвоёИмя\plasma-dog>
```

Это значит «мы внутри папки программы». Отлично.

---

## Шаг 8. Установи «начинку» программы

Эта команда докачает всё, что нужно программе для работы (камера, окно, кодеки). Вставь и нажми Enter:

```powershell
uv sync
```

> ⏳ **Это самый долгий шаг — от 2 до 5 минут.** Качается несколько больших кусков (библиотека камеры и интерфейса). Будут бежать строчки и полоски прогресса — **это нормально, просто жди**. Не закрывай окно. Когда снова появится `PS C:\...\plasma-dog>` — готово.

---

## Шаг 9. Запусти программу! 🎉

Финальная команда. Вставь и нажми Enter:

```powershell
uv run plasma-dog
```

Через несколько секунд **откроется окно программы** plasma-dog. Поздравляю — она работает!

> 🔎 **Окно не появилось?** Посмотри на **панель задач** внизу экрана — программа может открыться свёрнутой или за другими окнами. Кликни по её значку, чтобы развернуть.
>
> ⬛ **Чёрное окно PowerShell остаётся открытым**, пока работает программа — это нормально. Не закрывай и не трогай его, иначе программа закроется.
>
> 📷 Если Windows спросит разрешение на доступ к камере — нажми **«Да» / «Разрешить»**. Подробнее про камеру — следующий шаг.

---

## Шаг 10. Разреши доступ к камере

Чтобы программа увидела твою USB-камеру:

1. **Воткни USB-камеру** в компьютер, если ещё не воткнул.
2. Проверь разрешения Windows:
   - Открой **Пуск** → набери **«Камера»** → выбери **«Параметры конфиденциальности камеры»** (или: Параметры → Конфиденциальность и защита → Камера).
   - Включи переключатели **«Доступ к камере»** и **«Разрешить приложениям доступ к камере»**.
   - Чуть ниже включи также **«Разрешить классическим приложениям доступ к камере»**.
3. Вернись в окно программы plasma-dog. Вверху нажми кнопку **«Обновить»** — программа заново найдёт камеры.
4. Выбери свою камеру из выпадающего списка вверху.

**Что ты должен увидеть:** в окне появится «живая» картинка с камеры (превью), а сбоку — панель с ползунками настроек (яркость, экспозиция и т.д.).

---

## Шаг 11. Как пользоваться (коротко)

1. Вверху окна **выбери камеру** из списка (кнопка **«Обновить»** пересканирует устройства, если камеру воткнул позже).
2. Дождись «живой» картинки с камеры.
3. При желании подвигай **ползунки** сбоку (экспозиция, усиление, баланс белого и т.д.) — картинка меняется сразу.
4. Открой **Файл → Настройки…** (или нажми **Ctrl + ,**), чтобы выбрать:
   - **папку**, куда сохранять записи;
   - **формат** отдельных кадров (PNG / JPG / BMP);
   - **горячую клавишу** старт/стоп.
   - 💡 Здесь же видно, в какую папку попадут записи — запомни её, чтобы потом найти файлы.
5. Нажми кнопку **REC**, чтобы начать запись (или горячую клавишу, по умолчанию **Ctrl + R**). Чтобы запись сама остановилась через N секунд — задай число в таймере и нажми **«REC с таймером»**.
6. Нажми **Stop** (или ту же горячую клавишу ещё раз), чтобы корректно завершить запись. Программа дозапишет всё и сохранит файлы.

Внутри папки записи ты найдёшь видео (`video.mp4`), папку с кадрами (`frames/`) и файл `metadata.json` с параметрами съёмки.

**Чтобы закрыть программу** — просто закрой её окно крестиком ✕. Окно PowerShell после этого тоже можно закрывать.

---

## Шаг 12. Как запускать программу в следующий раз

Устанавливать всё заново **не нужно** — это делается только один раз. В следующий раз, чтобы запустить программу:

1. Открой **PowerShell** (Пуск → `powershell` → Enter).
2. Вставь эти две команды по очереди:

   ```powershell
   cd plasma-dog
   ```

   ```powershell
   uv run plasma-dog
   ```

Окно программы откроется. Всё.

### 💎 Бонус для ленивых: запуск в один клик

Чтобы каждый раз не открывать PowerShell, можно сделать **ярлык на рабочем столе**, который запускает программу по двойному клику:

1. Открой **Пуск** → набери **«Блокнот»** → открой его.
2. Скопируй и вставь в Блокнот ровно это:

   ```bat
   @echo off
   cd /d "%USERPROFILE%\plasma-dog"
   uv run plasma-dog
   ```

3. В Блокноте: **Файл → Сохранить как…**
4. Внизу в поле **«Тип файла»** выбери **«Все файлы (*.*)»** (это важно!).
5. В поле **«Имя файла»** впиши: **plasma-dog.bat**
6. Слева выбери **«Рабочий стол»** и нажми **«Сохранить»**.

Теперь на рабочем столе есть значок **plasma-dog** — **двойной клик** по нему запускает программу. Готово, больше никаких команд.

## Если что-то пошло не так

Найди свою ситуацию в списке.

### 1. «winget не является именем командлета» / «winget не распознано»

Твоя Windows старовата или в ней нет «App Installer».

- Сначала **обнови Windows**: Пуск → Параметры → Центр обновления Windows → Проверить наличие обновлений. Перезагрузись и попробуй снова.
- Если не помогло — открой **Microsoft Store**, найди в поиске **«App Installer»** и установи/обнови его. Затем переоткрой PowerShell.

### 2. «python не является именем командлета» (после установки)

В 99% случаев причина — **не переоткрыл PowerShell** после установки (Шаг 5).

- Закрой окно PowerShell крестиком и открой заново. Проверь снова.

### 3. «uv» или «git» не является именем командлета (после установки)

То же самое — **закрой и открой PowerShell заново** (Шаг 5). Если уже переоткрывал, а `uv --version` или `git --version` всё равно не работают — перезагрузи компьютер целиком и попробуй ещё раз.

### 4. Камера не находится / картинка чёрная

- Убедись, что **USB-камера воткнута**.
- Проверь разрешения Windows (Шаг 10) — оба переключателя и «классические приложения» должны быть включены.
- В окне программы нажми **«Обновить»**.
- Проверь, видит ли камеру сама Windows: Пуск → набери **«Камера»** → открой стандартное приложение «Камера». Если и там нет картинки — проблема в самой камере/USB, а не в программе. Попробуй другой USB-порт.

### 5. Программа не открывается / ошибка про «.dll» (например, VCRUNTIME140.dll)

Не хватает системного компонента **Visual C++ Redistributable**.

- Скачай его по ссылке (открой в браузере): **https://aka.ms/vs/17/release/vc_redist.x64.exe**
- Запусти скачанный файл, нажми **Install / Установить**, дождись конца, перезагрузись.
- Снова запусти программу (Шаг 12).

### 6. При записи ошибка про кодек / `avc1` / `cv2.error`

Программа умеет сама переключаться на запасной кодек, поэтому чаще всего запись всё равно идёт. Если видео не записывается:

- В программе открой **Файл → Настройки… → Кодек видео** и выбери **MJPG** — он работает почти везде (файл будет крупнее, но надёжно).

### 7. `uv sync` завис или выдал ошибку про сеть/скачивание

- Проверь **интернет** (открой любой сайт в браузере).
- Если используешь **VPN** — иногда он мешает; попробуй выключить и повторить.
- Просто запусти команду `uv sync` ещё раз — она продолжит с того места, где остановилась.

### 8. Выскакивает окно «Разрешить приложению вносить изменения на устройстве?»

Это обычный запрос безопасности Windows при установке. Нажимай **«Да»**.

---

## Что вообще установилось на компьютер (для общего понимания)

Тебе это знать не обязательно, но если интересно:

- **Python** — «движок», на котором написана программа.
- **uv** — помощник, который скачивает и собирает все нужные части программы.
- **git** — инструмент, которым мы скачали программу с интернета.
- **Папка `plasma-dog`** (в `C:\Users\ТвоёИмя\plasma-dog`) — это и есть сама программа со всеми файлами.

Удалять что-либо из этого не нужно. Всё это безопасно и используется множеством обычных программ.

---

Если совсем ничего не получается — сделай скриншот окна с ошибкой (клавиша **Print Screen**, затем вставь в сообщение через Ctrl+V) и отправь тому, кто дал тебе эту инструкцию.
